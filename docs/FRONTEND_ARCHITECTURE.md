# Vaidya — Frontend Architecture

## Framework: Next.js 14 App Router
## Language: TypeScript
## Styling: Tailwind CSS + CSS Custom Properties
## State: Zustand (global) + TanStack Query (server state)
## Forms: react-hook-form + zod
## Animation: framer-motion
## Icons: lucide-react
## Charts: recharts

## Surfaces
- /patient/* — Patient intake (no sidebar, touch-first)
- /doctor/* — Physician workspace (sidebar, information-dense)
- /nursing/* — Triage (sidebar, alert-oriented)
- /admin/* — Administration (sidebar, analytics-oriented)

## NOT INCLUDED
- /kiosk — separate future application
